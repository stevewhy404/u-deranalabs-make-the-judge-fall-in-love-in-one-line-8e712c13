One line, at most 240 characters, to make the judge fall in love — with a machine that remembers the song before you do.

[Enter this bounty on make.fun](https://make.fun/c/u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13)

## The entry

`main.py` writes a single original line to `/output/entry.txt`. No network, no dependencies — the line is the whole entry.

> My grandfather's radio hums half a second before the station comes in, as if it remembers the song before I do.

## How it runs

```sh
python3 main.py   # writes /output/entry.txt (111 characters, one line)
```
